# 视觉身份：国朝墨彩 (Imperial Ink & Color)

**状态**: 已在 game-concept.md 中作为 Visual Identity Anchor 确认，美术圣经第1章待写入

## 核心规则
水墨笔触的环境 + 鲜活的拟人动物角色 + 2:1 等距 3D 构图，像一幅会动的中国宫廷卷轴画

## 一句话视觉规则（第1章草稿）
选更像「宋代院体画里跳出来的武侠」的方案，而不是更酷的那个。

## 三色语义系统
- 绛红 #9E2F2C — 危险 / 玩家攻击
- 石青 #1685A9 — 信息 / 节奏指示
- 金 #FFD700 — 奖励 / Perfect 判定
- 规则：新增颜色必须先归入三色语义；无法归入则用灰度水墨处理

## 字体系统
- 汉仪尚巍手书 — 标题 / 武器名 / Boss 名
- 思源宋体 — 正文 / HUD 数字
- 注意：商用授权需在 M0 阶段确认（v1 教训）

## 节拍驱动视效原则
所有 UI 动画、特效脉冲、屏幕边缘光晕随 BPM 呼吸。
关掉音量的玩家也应能「看见」节奏。

## 非游戏参考
- 宋代院体画 — 留白构图规则（环境背景基准）
- 中国皮影戏 — 角色剪影清晰度和夸张动作弧线
- 传统打击乐（编钟、木鱼、丝弦）— 判定音效音景（视效协同）

## 明确禁止方向
1. 赛博朋克霓虹 UI（破坏三色语义，违背华风沉浸）
2. 次世代写实风角色（破坏水墨层次差，资源不可支撑）
3. 与 BPM 脱钩的固定时长特效（违背节奏即战斗核心）

**Why:** 这些方向每一个都是在放弃本作唯一的视觉差异化锚点。
**How to apply:** 每次评审资产时，先对照禁止方向做排除检查，再做正向评估。
