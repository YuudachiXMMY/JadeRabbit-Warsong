# 用户档案

## 角色
独立游戏开发者 / Creative Director，同时担任《玉兔:破阵》的游戏设计负责人。
以 AI Agent 团队辅助开发，自己做最终决策。

## 视觉背景
- 对中国传统文化美学有明确的认知锚点（皮影戏、宋代院体画、传统打击乐）
- 已完成过一个 v1 版本（有美术资源空缺、未授权资产等教训），v2 要求早期建立规范
- 对「泛化就是放弃差异化」有清醒认识，愿意坚守窄众定位

## 协作偏好
- 提供详尽上下文（游戏支柱、参考资料、已有锚点），希望艺术总监在这个基础上扩展而非推翻
- 要求具体可操作的设计测试，而非形容词式描述
- 字数有约束意识（本次要求不超过800字），简洁优先
- 技术术语和颜色代码保留英文，其余中文

## 已知教训（来自 v1）
- 美术资源不能拖到后期才介入，必须早期定好代理资源规范
- 字体和第三方资产的商用授权必须在 M0 确认
