## 1. 视觉身份宣言

### 一句话视觉规则

**选更像「宋代院体画里跳出来的武侠」的方案，而不是更酷的那个。**

当两个视觉方案都在技术上可行、美感上各有优点时，用这句话打破平局：哪个方案让人感觉「这个东西属于这幅画」，选那个。

### 支撑原则

**原则一：墨场留白，色为刀锋**

- 核心内容：战场背景以水墨灰度为主体，遵循宋代院体画的经营位置——环境视觉重量控制在整体画面的 70% 以下，剩余空间是墨气与留白的交替。鲜色只出现在三个语义锚点上：绛红 #9E2F2C（危险/玩家攻击）、石青 #1685A9（信息/节奏指示）、金 #FFD700（奖励/Perfect 判定）。颜色出现就携带信息；装饰性用色等于噪音。
- **设计测试**：「当一个新 UI 元素或特效使用了三色语义之外的颜色，这条原则说——先问它传递了哪条语义信息；若无法回答，退回灰度水墨处理，或将其归入最接近的语义色」
- 锚定支柱：支柱三「华风沉浸 (Chinese Cultural Authenticity)」

**原则二：脉搏先于装饰**

- 核心内容：每个战斗视觉资产的第一设计维度是它与 BPM 时钟的关系，第二才是静帧美感。UI 缩放、特效爆发、屏幕边缘光晕的节拍周期必须锁定到当前曲目的实际 BPM。「节奏视觉」不是动画师在最后一步叠加的点缀层——它是资产验收的前置条件。玩家关掉音量后仍应能从画面脉冲中感知节奏的存在。
- **设计测试**：「当攻击特效方案 A 视觉更华丽但不随 BPM 脉冲、方案 B 视觉相对克制但呼吸感与 BPM 精准同步，这条原则说——选 B；再在 B 的基础上提升质感，不可颠倒顺序」
- 锚定支柱：支柱一「节奏即战斗 (Rhythm IS Combat)」

**原则三：兔为主角，笔为肉身**

- 核心内容：拟人动物角色的造型语言来自中国皮影戏的剪影美学——轮廓在任何背景下一眼可辨，动作弧线夸张而非写实，色彩高饱和以制造与水墨背景的层次差。角色不是贴着水墨场景存在的 3D 模型；它是从画卷里走出来的、唯一「活」的存在。动物比例的写实精度让位于文化辨识度：这是武侠，不是自然纪录片。
- **设计测试**：「当角色方案 A 的兔子形态更接近真实兔子解剖比例、方案 B 的剪影更接近皮影戏的夸张轮廓，这条原则说——选 B；轮廓清晰度直接影响玩家在战斗中读取自身位置和出手时机的精度」
- 锚定支柱：支柱二「武侠手感不可妥协 (Wuxia Feel First)」

### 视觉反例（禁止方向）

**禁止一：赛博朋克 / 电子霓虹 UI 语言**

具体表现：发光霓虹轮廓线、渐变紫蓝面板、电路板纹理作为 HUD 设计语言，将节奏感视觉化为电子光效。

为何禁止：三色语义系统立即失效——当屏幕上充斥渐变紫和电蓝，「石青 = 节奏信息」的感知映射被覆盖，玩家无法建立颜色与行动的反射关系。同时直接违背支柱三：这是另一个宇宙的视觉语言，与宋代院体画零关联。

**禁止二：次世代写实风角色（对标《黑神话》的 PBR 品质期望）**

具体表现：角色使用次世代写实光照（SSS 皮肤、PBR 毛发）和真实动物解剖比例，场景使用精细石材、砖瓦物理纹理。

为何禁止：角色与水墨背景的层次差消失，原则三的剪影结构被破坏；更深的问题是这条路的资源门槛远超独立团队可承受范围。追求写实风格将同时输掉品质竞争和风格差异化这两场仗。

**禁止三：与 BPM 脱钩的固定时长特效**

具体表现：Perfect 判定触发一个固定 0.3 秒的金光爆炸动画，每次表现相同，不随曲目 BPM 变化。

为何禁止：Perfect 是节奏系统的最高评级——它的特效必须强化「我踩准了节拍」的感知，而非仅表达「我打到了敌人」。与 BPM 脱钩的特效在视觉层告诉玩家音乐和战斗是两件事，这是对支柱一「节奏即战斗」的根本性背叛。每一次 Perfect 爆发，都是这首曲子在那个拍点上的应答。

## 2. 氛围与基调

### 全局约定：BPM 对视觉的作用机制

在进入各状态前，先锚定本章的核心维度——**BPM 呼吸**在视觉上的具体表现形式：

- **脉冲幅度**：屏幕边缘光晕、石青节奏环的缩放比例，随 BPM 线性映射。BPM 80 时幅度 ±4px，BPM 160 时幅度 ±12px。
- **墨气闪动**：水墨背景的墨迹笔触边缘在每个 beat 微微扩散再收缩（强拍幅度约弱拍 1.8×）。
- **三色系统同步**：石青（节奏指示）随 BPM 节拍闪烁；绛红（攻击特效）触发时叠加一帧高亮；金（Perfect）只在判定瞬间爆发，不持续呼吸。

### 状态 1：主菜单 / 大厅

**主情绪目标**：科场放榜前廊下等候的那种沉默——期待潜藏在肃穆之中，还未点燃。

**灯光特性**：
- 色温：偏冷，宫廷夜色，非正午自然光
- 对比度：low-mid（无强烈明暗剪切）
- 光源：从屏幕上方斜入，模拟悬挂宫灯的漫射光，无硬边投影
- 时辰感：傍晚日落后约半个时辰，天边仅余一线暗青

**墨气浓度**：淡墨主导（约 35%），留白区域大，背景墨迹用枯笔表现宫墙砖缝与远处轮廓。

**节奏视觉强度**：微弱。BPM 约 60-70 的慢呼吸；石青节奏环以最小幅度（±2px）缓慢律动，如同熟睡的心跳，不打扰视线停留。

**氛围描述词**：肃穆、屏息、悬置、含蓄、未燃

**能量水平**：沉稳（边缘隐藏张力）

**过渡策略（→ 探索走廊）**：进入一局后，BPM 从 65 线性加速至目标值；墨气浓度在 3 秒内从 35% 推至 55%；光源色温小幅上移向暖色过渡，暗示「入阵」。

### 状态 2：探索 / 走廊

**主情绪目标**：锦衣卫踏过宫廷回廊的那种警觉——战斗已经结束，但耳朵还竖着。

**灯光特性**：
- 色温：中性偏暖（廊下壁灯的桐油灯质感）
- 对比度：mid（走廊两侧有阴影，中央通道保持亮度）
- 光源：侧向低位光，来自走廊两侧宫灯，产生柔和侧影
- 时辰感：深夜，宫廷人迹散尽

**墨气浓度**：中墨（55-60%），走廊尽头用浓墨压暗，营造纵深感，前景保持清晰可读。

**节奏视觉强度**：静默至微弱。走廊内 BPM 呼吸降至最低，石青环几乎静止，告知玩家「此刻不在节奏压力中」。若玩家拥有「连击保留心法」，石青微脉冲提示连击状态仍活跃。

**氛围描述词**：警觉、悄然、喘息、深宫、窥探

**能量水平**：紧张（低频但持续）

**过渡策略（→ 普通战斗房）**：踏入战斗房时，触发 0.5 秒「门开」动画——墨气从走廊 55% 骤升至 70%，BPM 瞬间恢复目标战斗值，石青节奏环从静止加速到当前 BPM 呼吸频率，完成听觉-视觉双重「入场仪式」。

### 状态 3：普通战斗房

**主情绪目标**：鼓师第一槌落下，编钟作响，身体先于大脑开始移动。

**灯光特性**：
- 色温：暖色主导，铜钟金属反光质感，带红橙底色
- 对比度：high（地面拍点格高亮，阴影区域压黑，强化视觉节奏感）
- 光源：顶光为主 + 地面散射，配合绛红攻击特效补光
- 时辰感：时辰在此不重要——这是一个「被节奏接管的空间」

**墨气浓度**：中墨（60-65%），足够让彩色角色和三色特效跳脱，又不抢视觉焦点。

**节奏视觉强度**：中等至强烈。BPM 呼吸可见，屏幕边缘光晕每拍闪动；攻击命中时绛红补光闪烁；Perfect 判定时金光在角色位置爆发 1 帧全屏亮度峰值（非持续）。

**氛围描述词**：燃烧、精准、爆发中的克制、锋利、专注

**能量水平**：激昂（受控的，非混乱的）

**过渡策略（→ 精英房）**：精英房入口用浓墨遮挡（80%），进入时墨幕短暂覆盖全屏，如同翻页，暗示「此页不同寻常」。

### 状态 4：精英 / 事件房

**主情绪目标**：佛寺暮钟后山门外的清冷——地方是熟悉的地方，但此刻站在这里，重量不同了。

**灯光特性**：
- 色温：冷色偏石青，褪去普通战斗房的暖橙，增加庙堂清肃感
- 对比度：high（阴影更深，高光更集中于敌方精英单位）
- 光源：从上方单一强光源打下，营造「聚光」感，边缘完全黑暗
- 时辰感：子时，最沉的黑暗

**墨气浓度**：浓墨（70-75%），环境压迫感明显，背景几乎无留白。

**节奏视觉强度**：强烈。BPM 呼吸幅度加大，石青节奏环增粗一级（4px → 6px 线宽），精英敌人攻击前摇时绛红预警光晕比普通敌人扩散得更慢、更显眼。

**氛围描述词**：肃杀、沉压、凛然、高张力、庄重

**能量水平**：紧张（高密度，喘不过气）

**过渡策略（→ Boss 战）**：Boss 门以金色镶边高亮，是整个 run 中第一次允许金色作为环境装饰出现（此前金仅用于 Perfect 判定），暗示「终点已近，此处是奖励」的信号逻辑对立。

### 状态 5：Boss 战

**主情绪目标**：武将在阵前对阵时的那种——「我知道你很强，但我已准备好了」。

**灯光特性**：
- 色温：动态——Boss 第一阶段偏冷石青，二阶段转向绛红，暗示危险升级
- 对比度：极高（Boss 身体高亮轮廓，背景近乎全黑，两者之间无过渡色阶）
- 光源：Boss 自身作为次要光源，随攻击前摇向外辐射
- 时辰感：超越时辰——这是一个「仪式空间」

**墨气浓度**：浓墨主导（80%+），背景留白几乎消失，只有 Boss 和玩家在「墨海」中战斗。

**节奏视觉强度**：爆裂。BPM 可能切换拍号（4/4 → 3/4），视觉呼吸节奏随之重新同步——这是玩家感受到「规则改变」的视觉信号之一。Boss 每次进入新阶段时，全屏石青闪光 2 帧作为拍号重置信号。

**氛围描述词**：史诗、孤注一掷、极度专注、震撼、仪式

**能量水平**：狂喜（恐惧与兴奋的同一体）

### 状态 6：死亡 / 结算

**主情绪目标**：武侠倒下后仰望天花板的那几秒——不是悲剧，是「这一局我学到了什么」的沉淀。

**灯光特性**：
- 色温：极冷，去饱和，如同画面在褪色
- 对比度：low（高对比度柔化，战场的锐利退去）
- 光源：光源收缩，只剩顶部一点散光，如同记忆中的光
- 时辰感：黎明前，最后一刻的黑暗

**墨气浓度**：留白主导（25-30%），墨迹大量晕散，笔触松开，像一幅被水浸湿的画。

**节奏视觉强度**：静默。BPM 停跳。石青节奏环完全消失。功勋数字用金色（语义正确：这是奖励）逐帧浮现，是全屏唯一的色彩亮点。

**氛围描述词**：沉落、余温、记录、回旋、未完

**能量水平**：肃穆（但带有「下一局」的潜台词）

**过渡策略（→ 主菜单 / 新一局）**：功勋结算完成后，画面用枯笔白墨自中心向外扩散，「洗白」当局，引导视线到「再来一局」按钮——石青节奏环以 BPM 60 重新开始微弱呼吸，新一轮的「等待点燃」从这里重来。

## 3. 形态语言

### 一、角色剪影哲学

**原则：剪影是战场上最快的信息传递单位。**（锚定原则三：兔为主角，笔为肉身）

**等距视角下的尺寸规则：**

2:1 等距视角中，主角占画面垂直高度的 14-18%（1080p 下约 150-195px）。缩略图测试基准：在 64×64px 下，角色剪影必须在无颜色辅助的情况下可辨识身份类型（主角 / 大型敌人 / Boss）。具体执行：美术交付时必须附一张 64×64px 灰度剪影截图作为验收件。

**主角（玉兔武侠）的剪影识别特征：**

- 耳朵——两只长耳垂直向上延伸，是角色轮廓的最高点。等距俯视角下耳朵成为「天线」，在任何混战中都突出于其他单位。耳朵高度不可被任何装备完全遮挡。
- 腰身——纤细腰部 + 宽袍下摆形成上细下宽的三角形重心，传达「稳而随时可弹射」的感知。
- 武器伸出方向与身形形成非对称的负空间，负空间是剪影辨识的第二信息层。

**角色类型剪影区分规则：**

| 类型 | 轮廓几何特征 | 传达情绪 |
|---|---|---|
| 主角（玉兔） | 纵向延伸 + 耳高点 + 三角重心 | 敏捷、灵动、克制 |
| 普通敌人 | 横向宽体，矮于主角，无突出特征点 | 量感、可消耗、群体威胁 |
| 精英敌人 | 高于主角 10-15%，肩宽突出，有一个不对称装饰件（头盔、法器） | 分量、值得警觉 |
| Boss | 屏幕占位 ≥ 35%，形态包含曲线与直线的强烈对比，轮廓有「破框感」——即超出等距格子的视觉边界 | 压迫、仪式感、规则破坏者 |
| NPC / 商人 | 圆润轮廓，无尖锐延伸，双手可见（非战斗姿态） | 安全、功能性、喘息 |

**武器对剪影的影响：**（锚定原则三 + 支柱二）

- 苗刀：刀身修长，在等距角度斜向延伸，剪影呈「对角线张力」——传达流动与速度。
- 长枪：竖向穿出角色头部上方，与长耳形成「三根天线」排列，是最易辨识的武器剪影。
- 剑：短而宽，不突出角色轮廓边界，剑气特效补充其存在感——剑的形态语言靠动效而非静态剪影。
- 规则：武器轮廓与角色轮廓叠加后，最终合并剪影的复杂度不得超过 7 个关键拐点（转折点），保持 64×64px 下可读。

### 二、环境几何语言

**宫廷迷宫的建筑形态：直线主导，曲线作为语义标记。**（锚定支柱三：华风沉浸）

宋代院体画的建筑描绘来自界画传统——以界尺作直线，建筑精准、方正、秩序感强。游戏中的宫廷迷宫继承这一规范：墙体、廊柱、房间边界全部使用硬直角（90°）或 45° 斜线（等距投影的自然角度），绝不使用有机曲线处理建筑轮廓。

曲线被保留为语义专有形态：出现曲线的地方意味着「非人工」（水面、树冠、荷花）或「超自然」（Boss 腐化区域的流体扭曲），是视觉上的异常信号。

**等距地板的形态处理：**

- 正常地面：45° 斜格石板，线条粗细随距离递减（近粗远细），强化深度感知，符合水墨线描的浓淡节奏。
- 节拍格（Rhythm Beat Zone）：正方形高亮格，出现在拍点位置，石青边线，内部无填充，保持地面可读性。节拍格是地面上唯一出现曲线的例外——格的四角有微弱的圆角过渡（4px radius），与硬边建筑形成区分，传达「这是游戏系统的信号，不是建筑的一部分」。
- 水墨渍：仅出现在死亡事件区域或 Boss 阶段切换时的过渡地面，圆形晕散，直径不超过 3 个格子，是环境叙事的形态标记，不作装饰。

**可交互 vs 不可交互物体形态规则：**（锚定原则一：墨场留白，色为刀锋）

- 可交互（宝箱、传送门、道具）：轮廓线比同尺寸环境物厚 1.5-2×，且在静止状态有微弱的石青描边呼吸（BPM 同步）。形态上保留一个「握持暗示」——宝箱盖子有微开缝、传送门内有轻微光粒流动。
- 不可交互（柱子、墙饰、地砖纹理）：线宽相同，无彩色边线，统一纳入水墨灰度体系，饱和度低于 5%。

**前/中/背景深度层次的形态手段：**

- 前景（相机最近层）：最粗线宽（3-4px at 1080p），浓墨轮廓，高对比，细节最丰富。
- 中景（战斗层）：中等线宽（2px），这是角色和交互物体所在层，色彩信息集中于此。
- 背景（宫廷远景）：最细或消失的轮廓线（0.5-1px），以墨色面块而非线条表现，用大量留白强制视线停留在中景。背景元素没有完整轮廓，像是被水稀释开的笔墨。

### 三、UI 形态文法

**UI 语言与世界观共用一套形态根源，但保持功能优先。**（锚定原则一：色为刀锋；原则二：脉搏先于装饰）

UI 不是独立的 HUD 浮层——它是卷轴的一部分。所有 UI 面板的形态出发点是「竹简或绢帛的物理边界」，而非现代 app 的矩形卡片。

**面板与按钮的基本形状来源：**

- 主要面板：横向长矩形，比例接近 4:1（类竹简），左右两端以 45° 斜切角收边（非圆角），传达竹简两端被截断的材质感。这是全游戏最常见的 UI 容器形态。
- 次要信息条（血条、气槽）：细长横条，两端斜切，无圆角，线宽 2px 边框。
- 按钮：正方形或接近正方形，四角 45° 斜切，与面板形态呼应。绝不使用圆角矩形（圆角是现代 app 的形态记忆，与宋代审美体系冲突）。
- 禁止使用的 UI 形态：气泡提示框（有机圆形轮廓）、浮动圆形按钮（传达移动 app 语义）。

**石青节奏环的形态设计原则：**（锚定原则二：脉搏先于装饰）

- 形态：等宽线圆环，围绕玩家角色，半径约为角色最大横向宽度的 110%，保持一圈完整可见。
- 静息状态：线宽 4px，透明度 60%，随 BPM 做 ±幅度缩放。
- 激活状态（攻击窗口）：线宽 6px，透明度 90%，缺口出现在 12 点方向（朝向等距相机），缺口角度 = 当前判定窗口的宽度（Perfect 窗口越宽，缺口越小）。缺口是功能性形态，传达「此处是精准瞄准点」。
- 不可添加的装饰：箭头、文字标注、图标——节奏环是玩家的感知器官，信息密度不可升高，只能靠形态变化传达状态。

### 四、主角形态 vs 配角形态

**永远只属于主角的视觉元素：**（锚定原则三：兔为主角，笔为肉身；支柱二：武侠手感不可妥协）

1. 长耳轮廓——所有敌人角色禁止设计竖向高耳，以保护主角的最高辨识点专属性。
2. 石青节奏环——节奏环是主角的 HUD，不向任何非玩家单位复用此形态。
3. 动作弧线残影：主角高速移动时留下 3 帧水墨残影（同色系，透明度递减），敌人不拥有此效果。残影是「主角正在施展武侠功夫」的视觉宣言，属于原则三直接体现。

**混战中的主角追踪机制（形态手段）：**

- 主角轮廓线比任何敌人粗出 0.5px（2.5px vs 2px），这个差值在 64×64px 截图测试中可见。
- 主角的「地面投影」（Isometric Shadow）使用绛红色调（低饱和，约 30% 绛红混入灰），敌人投影使用纯黑灰。颜色区分在同屏 15 个以上单位时提供额外追踪线索。
- 主角的动作中心始终是石青节奏环的圆心——节奏环本身是一个「主角位置标记器」，玩家永远知道圆心在哪里，即知道主角在哪里。

**敌人与 Boss 形态对比主角的方式：**（锚定支柱三：华风沉浸）

- 普通敌人：几何更简单，关键拐点 ≤ 5 个，批量感强——这是形态上的「量产」信号，玩家无意识判断「这些可以批量解决」。
- 精英敌人：引入一个非对称形态元素（单侧肩甲、法冠、巨型旗帜），打破对称性传达「此处有个体」。非对称在视觉上等同于「威胁升级」，这是 Gestalt 原则中对称性（Symmetry）暗示稳定、非对称暗示张力的直接应用。
- Boss：形态语言主动打破等距几何规则——Boss 的某个形态元素（翅膀、法袍拖尾、武器光芒）会溢出等距格子的边界。「破框」是 Boss 的专属形态特权，传达「此存在不受宫廷秩序约束」，锚定 Boss 的叙事地位。

## 4. 配色系统

本章调色板分为两个层级：**语义色**（全游戏颜色词汇的强制锚点）与**氛围色**（服务于视觉层次和角色/环境的非语义色）。语义色携带行动信息，氛围色只承担造型与深度职责。两者不可互换位置。

### 一、主调色板（Primary Palette）

#### 语义色（Semantic Colors）— 三色系统

| 色名 | Hex | 语义 | 使用场景 | 禁止出现 |

| **石青** Azure | `#1685A9` | 信息 / 节奏指示 / 玩家主体 | 节奏环、判定窗口提示、节拍格边线、连击状态标志、可交互物石青描边 | 敌方任何 UI 元素、伤害特效、死亡结算屏主视觉 |
| **金** Gold | `#FFD700` | 奖励 / Perfect 判定 / 成就 | Perfect 判定爆发、功勋数字、Boss 门装饰（唯一允许用金做环境色的位置）、稀有道具边线 | Good / Miss 判定、普通地面装饰、走廊环境、UI 背景填充 |

### 二、语义用色规则

颜色词汇表是整个视觉系统的认知地图。每个颜色分配根植于中国传统色彩文化，并对应游戏支柱。

**红 / 绛红 = 杀伐与危险**

中国传统中，朱砂红是辟邪符咒的专用色，也是皇权敕令的朱批色——既是权威，也暗藏凶兆。本作将红锁定在「玩家的攻击行为」和「来自敌方的危险信号」，刻意排除了红色的「喜庆」语义。规则：屏幕上出现红色，玩家必须在 0.5 秒内做出响应。锚定支柱一（节奏即战斗）。

**青 / 石青 = 信息与秩序**

石青在中国传统绘画中是山水远峰、宫廷墙瓦的代表色，有「可信、持续、规律」的视觉语感。游戏中石青承载节奏系统的全部视觉信息——节奏环、拍点格、节拍指示——这些都是「秩序」的具象化：节奏是战斗的法则，石青是法则的颜色。锚定支柱一（节奏即战斗）和支柱三（华风沉浸）。

**金 = 成就与奖励**

金在中国皇权体系中是「最高等级」的专属色，非皇帝不可用金器、金漆。本作中金的出现频率是三色中最低的——只有 Perfect 判定（最高评级）、功勋数字（成就记录）、以及 Boss 门装饰（奖励临近信号）三个场景。稀缺性本身就是语义：看到金色，玩家知道「此刻发生了最好的事情」。锚定支柱四（构筑驱动复盘）。

**绿 = 不使用**

明确禁止将绿色作为独立语义色引入本作。理由：绿色在视觉上与石青产生混淆风险（尤其对红绿色盲玩家，石青与绿的区分本已困难），且游戏世界的「安全/治愈」概念通过「留白增加」和「BPM 降低」来传达，不需要额外颜色信号。若道具系统需要区分「回复类」道具，使用道具图标形态区分，不依赖绿色。

**白 = 宣纸与余烬**

白在宋代绘画中不是「空无」，是「留白」——是最有意图的一种表达。游戏中白色（宣纸白 `#F5F0E8`）服务于 UI 底色、留白区、结算屏扩散的「洗白」动画。白出现量的减少（→ 浓墨增加）等于压力升级；白出现量的增加（→ 留白扩张）等于解压和死亡的「放开」。白是墨气浓度的对面，两者共同构成视觉张力温度计。

**黑 = 墨气与威压**

浓墨 `#1A1A18` 是背景层的基础，不是「缺席」而是「在场」。宋代院体画的浓墨是积墨技法，多层叠加出深度感。游戏中墨气浓度越高，黑的比例越大——浓墨是压力的形态语言。Boss 战场景黑色占画面 80% 以上，这不是贫瘠，是在说「此刻你和对手是世界上仅存的两个东西」。锚定原则一（墨场留白，色为刀锋）。

### 三、区域 / 场景色温规则

游戏的「区域差异」不来自大幅改变调色板，而来自**色温偏移**和**墨气浓度**的组合变化，在保持水墨底色不变的前提下制造可辨识的区域感知。规则：任何一个区域的辨识度必须在墨气通道被剥离（灰度测试）后仍可被玩家感知——色温偏移必须强到在黑白下变成明暗关系。

| 区域类型 | 色温偏移 | 墨气浓度 | 区域感知锚点 |
| --- | --- | --- | --- |
| 外廷（权贵走廊） | 中性偏暖（桐油灯色 `#C8855A` 叠加层约 15%） | 55-60% | 宫廷庄重感，走廊幽深 |
| 内廷（秘室、典籍库） | 冷色（石青环境散射 `#1685A9` 叠加层约 10%） | 65-70% | 知识/秩序感，比外廷压抑 |
| 禁苑（花园、水榭） | 偏暖偏亮（月色，`#E8E2D5` 宣纸白散射约 20%） | 35-45% | 唯一允许的「喘息空间」，低墨气强制视觉松弛 |
| 禁地（腐化区域） | 冷紫偏移（`#4A2060` 氛围叠加层约 20%，非三色内颜色，唯一特例） | 80%+ | 「这里不属于正常宫廷体系」的视觉信号——曲线形态 + 紫色偏移双重标记 |

**禁地紫色的特例处理：** 腐化区域使用 `#4A2060` 低饱和暗紫作为环境叠加层，是本游戏唯一突破三色体系的颜色。允许理由：腐化区域在叙事上是「反常、异界、不可解释之物」，三色体系在此刻意失效，是对玩家发出的最强烈的「你离开了已知秩序」的视觉信号。执行限制：紫色**只能**作为半透明叠加层（不超过 25% 不透明度），不可用于任何 UI 元素或判定特效，不可与任何语义色（绛红/石青/金）直接相邻。

### 四、UI 调色板

UI 调色板是世界调色板的「提纯版」。世界中的颜色来自物理材质；UI 的颜色来自同一语义系统，但需要满足功能优先级：信息层级必须清晰，任何墨气浓度下的文字必须可读。

#### UI 底色与文字色

| 用途 | 颜色 | Hex | 理由 |
| --- | --- | --- | --- |
| UI 面板主背景 | 宣纸白（半透明） | `#F5F0E8` @ 85% | 竹简材质感，透过底色可见游戏世界，不完全遮挡 |
| UI 面板描边 | 浓墨 | `#1A1A18` | 竹简的墨框，与游戏世界轮廓线同一语言 |
| 正文 / 说明文字 | 深墨 | `#2A2820` | 在宣纸白底上 WCAG AA 合规（对比度 > 7:1） |
| 标题 / 武器名 | 浓墨 + 汉仪尚巍手书 | `#1A1A18` | 最高信息层级，最深颜色 |
| 数值 / HUD 数字 | 深墨（普通）/ 金（Perfect）/ 绛红（伤害） | `#2A2820` / `#FFD700` / `#9E2F2C` | 语义色直接承担数字颜色，颜色即类型 |
| 次要信息 / 提示 | 淡墨 | `#7A7466` | 信息层级降低，视觉重量轻于正文 |

#### UI 交互态颜色变化规则

UI 交互用形态变化主导，颜色变化辅助——遵循原则一（颜色携带信息，不作装饰）。

| 状态 | 外观 | 颜色变化 | 形态变化 |
| --- | --- | --- | --- |
| 默认 | 宣纸白面板，浓墨描边 | 无色彩 | 无 |
| 悬停（Hover） | 石青描边取代浓墨描边 | 描边 `#1685A9` | 轻微上移 2px（如纸张被风轻掀） |
| 按下（Pressed） | 石青描边加粗，面板压暗 5% | 描边粗 6px | 轻微下压 1px |
| 禁用（Disabled） | 全体降低至 40% 透明度 | 所有颜色 @ 40% | 无动态 |
| 聚焦（Gamepad Focus） | 石青描边 + BPM 呼吸闪烁 | 同悬停，但透明度随 BPM 呼吸 | 描边随 BPM 缩放 ±1px |

**不同墨气浓度下的 UI 可读性保障：** 当游戏背景墨气浓度超过 65%（精英房、Boss 战），UI 面板底色自动升至 95% 不透明度（从半透明切换为实色）。这是 UI 的唯一例外：不透明度是功能性参数，不是视觉审美偏好，可根据后景计算动态调整。该逻辑必须由 UI 程序员通过后景亮度检测实现，技术细节委托 `unity-ui-specialist`。

### 五、色觉无障碍（Colorblind Safety）

任何核心判定信息不得**仅靠颜色区分**——颜色是第一信息层，形态/动画/声音是冗余信息层，必须同时存在。

#### 高风险颜色对分析

**风险对 1：绛红 `#9E2F2C` vs 角色朱砂 `#D94F3D`**

红绿色盲（Deuteranopia）下两色均偏黄褐，亮度差约 15%，存在混淆风险。补偿手段：语义绛红始终出现于攻击特效和 AOE 预警，伴随粒子扩散动画（纯形态信号）；角色朱砂是静态服装色，不闪动、不粒子化。两者出现场景不重叠（一个动态，一个静态），利用时间维度区分。

**风险对 2：石青 `#1685A9` vs 桐油暖 `#C8855A`（环境光）**

三色色盲（Tritanopia）下两色均偏灰绿，亮度差约 20%。补偿手段：石青始终附带 BPM 呼吸动画（任何静止的石青色块不存在）；桐油暖是纯环境叠加层，无动态。

**风险对 3：金 `#FFD700` vs 宣纸白 `#F5F0E8`（UI 底色）**

Tritanopia 下金偏灰绿，与宣纸白相近。补偿手段：Perfect 爆发时，金色亮度峰值叠加全屏 1 帧的黑色遮罩底层；Perfect 判定同步触发编钟音效；Perfect 文字字号比 Good 大 40%（形态区分）。

#### 判定反馈 Colorblind 安全方案

| 判定 | 颜色 | 颜色外区分信号 | 安全评级 |
| --- | --- | --- | --- |
| **Perfect** | 金 `#FFD700` | 全屏亮度峰值 1 帧 + 字号最大 + 编钟音效 + 文字「Perfect」 | 安全（多重冗余） |
| **Good** | 石青 `#1685A9` | 节奏环轻闪 + 字号中等 + 轻音效 + 文字「Good」 | 安全（颜色与 Perfect/Miss 均无混淆风险） |
| **Miss** | 绛红 `#9E2F2C` | 屏幕边缘短暂绛红晕染 + 字号中等 + Miss 音效（钝音）+ 文字「Miss」 | 安全（颜色 + 屏幕边缘形态 + 声音三重区分） |

三个判定的文字标签（Perfect / Good / Miss）是不可删除的必要元素——这是兜底的纯文字信息层，确保在任何颜色感知场景下判定结果均可读取。

## 5. 角色美术方向

### 一、主角（玉兔武侠）视觉原型

**角色身份定义**

玉兔武侠的「年龄感」定格在武侠小说中的少侠阶段——身量已成，阅历未深。不是少年英雄的莽撞，也不是宗师级的沉淀，而是「刚刚够用的克制」。体型精瘦，是速度感的天然容器。外观传达「宫廷之夜我已见过太多，但今晚我仍然在场」的镇定。

性格通过视觉决策传达，不通过文字描述：

- 站姿：重心略偏前，待战非防御；非双手环抱的封闭体态
- 服装：束腰而非宽松，传达「随时可以移动」
- 耳朵：竖立而非贴颈，情绪静默下的高度警觉（锚定第3章：任何情绪状态下不可完全倒伏）

**服装设计方向**

朝代参考：**北宋武官便服**为基础，非宫廷礼服，非平民布衣——有制度感但保留行动自由度。

- 外袍：宽袍但束腰，下摆宽于上身（锚定第3章三角重心），衣摆在移动时有大弧度摆动，是残影系统（3帧水墨残影）的主要载体
- 主色：角色朱砂 `#D94F3D` 作为外袍主体，月白 `#E8E2D5` 作为内衬与耳朵内侧（锚定第4章，严禁使用语义绛红 `#9E2F2C` 于服装）
- 材质感：绢而非布，有光泽感——接近传统工笔画对丝绸的「线描留白」处理：轮廓线粗，内部线稀疏，用负空间传达材质
- 层次感：三层结构——最内月白领口、中层朱砂外袍、外层配件（武器背带、绑带）。靠线宽区分：外层 2.5px，内层 1px

**动物拟人化程度**

| 特征 | 保留（兔子） | 人化 | 禁止 |
| --- | --- | --- | --- |
| 头部 | 长耳（约头高1.5×）；较大眼睛；短口吻 | 直立二足；手指完整；面部可读情绪 | 写实兔子头骨比例；三瓣嘴；跖行后腿 |
| 身体 | 棉尾（臀部小圆尾）；肌肉量偏轻 | 人类躯干比例；直立脊柱 | 四足姿势；精细毛发纹理 |
| 皮毛 | 整体单色白（角色月白），耳尖有细微色差 | 宣纸纹理处理，非真实毛发 | 多色花纹；耳朵装饰纹 |

拟人化校准基准：对标 Hades 角色造型感——神话生物仍有非人特征但身体比例完全可操控。

**表情与姿势风格**

皮影戏表演原则：表情通过姿势而非面部微表情传达。

- 战斗中情绪由身体发出——重击后仰身回旋比皱眉更能传达「用力了」
- 立绘允许更丰富面部表情，但仍服务于「克制」方向
- 姿势夸张度：动作弧线夸张，但关键帧姿势干净——一个姿势传达一个信息
- 待机动画：呼吸起伏 + 耳朵微偏（向声源方向微倾），保持警觉感

### 二、敌人视觉原型

**普通敌人视觉身份**

设计起点：「宫廷卫兵」框架，动物拟人多样性，同属宫廷世界生命体系。

- **推荐动物**：猪（横向宽体，力量感）、狗（追踪/守卫）、熊（重击类型）。猫/狐留给精英/特殊类型
- **视觉统一**：宫廷制式盔甲，中等饱和度靠近氛围色，不使用朱砂/月白；盔甲质感比主角服装更「硬」——工笔勾线，无丝绸光泽
- **量产信号**：同类型共用基础轮廓，允许2-3变体（武器差异），基础剪影一致
- 关键拐点 ≤ 5个

**精英敌人视觉升级**

1. **非对称破坏**：引入一个不对称件（鬼头肩甲、倾斜法冠、非制式武器），64×64px灰度验收时可辨
2. **个体化**：疤痕、非制式改装、老化痕迹
3. **颜色升级**：允许在盔甲上引入**一块**语义绛红 `#9E2F2C` 装饰（如护肩边线、红缨），用量 ≤ 盔甲总面积 15%

**拟人化程度**：略低于主角——动物特征保留更多，身体比例更接近「动物套盔甲」。目的：强化主角的特殊性。

### 三、Boss 视觉哲学

**核心命题：这不是一个更强的卫兵，这是一条规则。**

- **造型来源不同**：普通/精英来自「制度」（盔甲、职阶）；Boss 来自「概念」（守阵的执念、被腐化的忠诚、宫廷秩序的具现）。Boss 首先是一个视觉命题
- **动静关系倒置**：Boss 静止时就已压满画面，是「巨大的静止物」
- **曲线回归**：Boss 的装束、附件、特效中可使用大量曲线（锚定第3章：曲线 = 超自然），与宫廷硬直角强烈对比

**Boss 情绪分阶设计**（对应第2章 Boss 战「仪式空间」）：

- **第一眼**：敬畏感——体积和破框形态完成
- **战斗中**：可解读感——形态包含清晰的攻击预示（附件发光、裙摆收缩），预示来自形态变化而非颜色
- **击败后**：收束感——死亡动画是「形态回归」：破框收回格子，曲线变硬直，轮廓消散成水墨渍

### 四、NPC 视觉方向

**「安全/功能性」视觉传达**

- **圆润即安全**：NPC 轮廓关键拐点 ≤ 4个，弧度代替锐角
- **双手可见**：默认姿势双手位于腰部或身前，无武器无遮挡
- **体型偏圆**：肥膘感强于精瘦感，功能角色的力量来自丰厚

**功能 NPC 造型方向**

| NPC 类型 | 动物参考 | 视觉差异化件 | 功能性形态标记 |
| --- | --- | --- | --- |
| 商人 | 兔（平民）/ 羊 | 算盘、铜钱串、宽袖收纳口袋 | 腰带低挂，头戴商人儒冠 |
| 铁匠 | 牛 | 皮革围裙、单侧厚手套 | 最宽 NPC 体型（劳动感）；熊已定为五品武官敌人，禁止与 NPC 共用 |
| 典籍官 | 白鹭 | 卷轴、文书夹 | 最高最细体型，无武器；鹤已定为一品文官 Boss 候选，禁止与 NPC 共用 |

NPC 服装统一使用氛围色系（中墨+淡墨+宣纸白），**不使用角色朱砂和月白**——主角是画面中色彩最鲜活的存在。

### 五、LOD 与相机距离

## 6. 环境美术语言

### 一、建筑风格与世界文化关系

**宫廷迷宫的建筑历史逻辑**

迷宫的本体是一座真实存在过的宫廷建筑群——不是幻想构筑，是腐化渗透了现实秩序之后留下的空间遗壳。建筑在叙事上的时间层是「北宋中晚期」：官僚体制成熟，权力走廊已然幽深，朝仪礼制达到顶峰，但运转机器的内部腐化开始无声蔓延。

建筑分为三个历史层：**礼制层**（正廊、朝仪厅、廊庑——象征「朝廷的脸面」）、**功能层**（典籍库、器物间、内侍居所——象征「朝廷的肌肉」）、**腐化层**（裂缝、扭曲空间、被遗弃区域——象征「秩序失效的现场」）。Level Designer 以此三层判断每个房间属于哪种建筑语境。

**建筑风格定位**

整体风格以北宋「界画」建筑描绘为形态基准：建筑物以直线、硬角、精准比例为主导。（锚定第3章：直线主导，曲线 = 非人工/超自然。）

朝代/地域参考优先级：

- 一级参考：北宋宫城（汴梁皇宫）——廊庑形制、斗拱承重、琉璃瓦色
- 二级参考：南宋院体画建筑背景——《清明上河图》城楼结构，李唐山水中的江南廊亭
- 三级参考：中国皮影戏布景——建筑作为「平面层」的遮挡与穿透感

材质方向：宫廷建筑优先呈现**石材、木构、琉璃、铜件**四类，以风格化笔触而非 PBR 表达。

**建筑与叙事的呼应**

建筑的秩序感本身就是叙事内容：等距视角下，工整的廊柱行列、对称的门窗分布、规律排列的地砖，传达「这里曾有强权维持着严密的秩序」。随着房间类型从走廊 → 战斗房 → 精英房 → Boss 房推进，建筑整洁度线性下降——柱子开始倾斜，地砖出现破损，门窗不再对称。这个渐变不需要文字说明。

### 二、纹理哲学

**风格化，非 PBR 写实。理由三重：**

1. 等距视角下 PBR 写实纹理的高光方向与固定相机角度产生永久性冲突
2. 视觉锚点是「宋代院体画」，笔墨意味不可被物理扫描质感替代
3. 风格化纹理在资源规模和修改效率上大幅优于 PBR 工作流

**各材质纹理处理方式**

| 建筑部位 | 纹理处理 | 等距有效密度 |
| --- | --- | --- |
| 墙面（石材） | 大色块底 + 稀疏缝线（淡墨 `#7A7466`），非均匀间距 | 低（≤ 3条/格） |
| 地面（石板） | 45°斜格，近景缝粗2px/远景0.5px，板内无纹理靠色块明度差 | 中（利用等距方向性） |
| 廊柱（木/石） | 竖向2-4条通直条纹，斗拱以轮廓表达不加纹理 | 极低（2-4条/柱） |
| 门窗（格扇） | 几何折线（冰裂纹、万字纹），1px线宽，与背景差值≥30% | 中高（纹理密度上限） |
| 屋顶（琉璃瓦） | 横向弧瓦行约8px间距，低饱和青灰（非语义石青），瓦缘浓墨1px | 中 |

**全局规则**：任何纹理在 256×256px 裁切下不得看起来像噪点；纹理方向优先与等距投影一致（水平/45°/竖直）；不可交互物件纹理饱和度 ≤ 5%。

### 三、道具密度规则

**各房间类型密度标准**（1080p 战斗房约 900×450px 为基准）

| 房间类型 | 道具密度 | 可交互 | 叙事物件 | 理由 |
| --- | --- | --- | --- | --- |
| 走廊 | 极低 | 0 | 1-2 | 过渡空间，视觉噪音打断喘息情绪 |
| 战斗房 | 低-中 | 1-2 | 2-3 | 战斗焦点是敌人和节拍格，道具只作深度锚点 |
| 精英房 | 中 | 2-3 | 3-4 | 道具参与环境叙事，但不加剧拥挤 |
| Boss 房 | 极低+仪式摆设 | 0 | 3-5 | 只放仪式化固定装置（香炉、武器架、屏风） |

**适合本世界的道具清单**

- 礼制层：朱漆柱鼓、铜制宫灯、御道旗架、朝官案几、砚台笔架
- 功能层：武器架、典籍架、香炉、茶具
- 叙事残迹：倒翻瓷碗、散落奏折、燃尽蜡台、破损屏风、未完棋局
- 禁止：现代器具、西洋物件、来源不明的 fantasy 道具

**布置构图规则**

1. **三角法则**：叙事焦点1件 + 背景道具2件 + 前景遮挡0-1件构成不等边三角形，优先沿45°对角线放置叙事焦点
2. **不遮挡节拍格**：战斗房道具不可置于 Rhythm Beat Zone 覆盖范围
3. **前景遮挡物**：须与场景有建筑依附关系，玩家接近时自动降至50%透明度
4. **宫灯锚点**：每房间≥1盏宫灯，颜色限桐油暖 `#C8855A`，禁止蓝白冷光

### 四、环境叙事指南

**无文字视觉叙事手段**

- 打斗痕迹：地砖碎裂（断裂线，非爆炸）、墙面浅色划痕、低饱和绛红血迹（≤ 1.5格圆形晕散）
- 人员痕迹：散落奏折、翻倒宫灯（=紧急撤离）、半开门（=有人刚离开）
- 时间痕迹：蜡台残迹（蜡泪凝固，流淌方向一致）、地砖角落积灰（明度暗10-15%）

**「被破坏的秩序」视觉化**

破坏规则 = 破坏直线和对称：廊柱倾斜5-10°、地砖缺块（浓墨面块填充）、屏风破损（框架留存绢面缺角）、门扇脱轴（单扇倒斜另一扇完好——不对称破坏比均匀破坏更显事件性）

**「曾经繁华」视觉化**

通过「高质量 + 废弃状态」并存：精细格扇纹完整 + 积尘压暗15%、完好宫灯架 + 宫灯缺失（空架比破碎架更凄凉）、整齐茶具 + 碗中凝固痕迹

**「腐化扩散」视觉化**

遵循第4章禁地规则（暗紫 `#4A2060` 叠加层）：地砖缝出现有机裂缝（唯一允许曲线的地面场景）、建筑角落水墨晕散（圆形渍无明确形态）、道具石青描边消失融入灰度——叙事含义：腐化吞噬秩序

**叙事物件标准**

- 必须有「可解读状态」：完好 / 损毁 / 腐化 三态之一，与所在房间历史层匹配
- 不可遮挡节拍格，不置于玩家动线中心
- 摆放方向须有情绪意图：整齐 = 未扰动，散落 = 有事件，半散落 = 事件被打断

### 五、深度与层次控制

**2:1 等距视角的深度创造四重手段**

1. **墨气浓度梯度**：前景最浅/线宽最粗 → 中景居中 → 背景最浓。每层明度差不少于20%
2. **色温层次**：前景中性偏暖 → 中景区域主色温 → 背景偏冷（冷色退远）
3. **线宽递减**：前景3-4px → 中景2px → 背景0.5-1px（锚定第3章）
4. **细节密度递减**：前景细节最丰富，背景只保留轮廓形态移除表面纹理

**前景遮挡物规则**

- 种类：廊柱局部、屋角挑檐、屏风边缘、帘布下摆
- 数量：每场景≤2个，超过则遮挡玩家方位读取
- 颜色：浓墨轮廓 + 氛围色填充，不使用语义色
- 透明度：玩家进入 XY 格子范围时降至40-50%
- 禁用场景：Boss 房、节拍格密集区域中心

**墨气参数指导**（技术实现委托 `technical-artist`）

| 层级 | 明度乘数 | 饱和度乘数 | 轮廓线 |
| --- | --- | --- | --- |
| 前景 | 1.0（不调整） | 1.0 | 3-4px |
| 中景 | 0.90 | 0.90 | 2px |
| 背景 | 0.75-0.80 | 0.40 | 0.5px |
| Boss 战背景 | 0.55 | 0.30 | 0.5px |

**视线引导路径**

Level Designer 须检查每房间的视线引导链：入口 → 房间中心（节拍格密集处）→ 主要敌人位置 → 出口，构成 S 形或 Z 形路径。宫灯放在转折节点（视觉路标），叙事焦点道具放在路径末端（出口附近），玩家完成战斗后自然发现叙事细节。

## 7. UI/HUD 视觉方向

### 一、界面空间策略：Diegetic Hybrid（拟境混合）

UI 分为两个空间层级，根据信息的**节奏关联度**决定归属：

**世界空间（World-Space）— 与节奏直接绑定的元素**

| 元素 | 归属理由 | BPM 同步 |
| --- | --- | --- |
| 石青节奏环 | 围绕玩家角色，是「节奏感知器官」 | 是（缩放呼吸） |
| 技能槽边框脉冲 | 技能冷却与节拍窗口对齐 | 是（边框亮度闪动） |

世界空间元素随角色移动，受等距相机透视影响，是角色身体的视觉延伸。

**屏幕空间（Screen-Space）— 状态信息与结算**

| 元素 | 归属理由 | BPM 同步 |
| --- | --- | --- |
| 血条 | 生命值是持续状态，非瞬时节奏信息 | 否 |
| 连击计数器 | 累计数字非瞬时节拍，需要稳定可读 | 否 |
| 结算面板 | 脱离战斗的信息汇总 | 否 |
| 全屏判定反馈（Perfect 爆发等） | 全屏效果必须脱离世界坐标 | 仅触发帧同步 |

屏幕空间元素固定于视口，不受角色位置影响，信息密度优先于沉浸感。

**归属判定规则**：新增 UI 元素时，问「这个信息是否需要玩家在拍点窗口内读取？」——是 → 世界空间；否 → 屏幕空间。

### 二、字体方向

**字体系统**

| 用途 | 字体 | 字号 | 备注 |
| --- | --- | --- | --- |
| 标题 / 章节名 / Boss 名 | 汉仪尚巍手书 | 72px | 每屏 ≤ 2 处使用，防止手书体过载 |
| 副标题 / 功能区域标题 | 汉仪尚巍手书 | 36px | |
| HUD 数字（血量、连击、伤害） | 思源宋体 Bold | 28px | 数字不使用手书体——可读性优先 |
| 正文 / 描述 | 思源宋体 Regular | 18px | |
| 次要提示 / 标签 | 思源宋体 Light | 13px | 最小可用字号 |

**字号层级规则**：72 / 36 / 28 / 18 / 13px 五级，相邻层级比例 ≥ 1.3×，保证信息层级在视觉上不可混淆。

**手书体使用限制**：汉仪尚巍手书在单屏内最多出现 2 处（如 Boss 名 + 章节标题），超过则手写质感变成噪音。所有功能性文字（数值、状态、按钮标签）一律使用思源宋体。

### 三、图标风格

**「描线减笔」图标语言**

图标造型基于工笔画的白描技法——以线条勾勒形态，内部不填充或仅单色块。

- 线宽：2px（与中景轮廓线一致）
- 颜色：单一语义色 + 浓墨 `#1A1A18` 轮廓。技能图标限定使用**一种**语义色（绛红 / 石青 / 金）+ 墨色，不允许多色混用
- 细节度：图标在 32×32px 下可辨识，不可有需要 64px 才可读的细节
- 风格禁止：渐变填充、光晕效果、写实材质贴图、3D 透视图标

**技能图标颜色规则**

| 技能类型 | 图标主色 | 理由 |
| --- | --- | --- |
| 攻击技能 | 绛红 `#9E2F2C` + 墨 | 攻击 = 危险语义 |
| 节奏增幅 / 被动 | 石青 `#1685A9` + 墨 | 节奏相关 = 信息语义 |
| 终极技 / 大招 | 金 `#FFD700` + 墨 | 最高级 = 奖励语义 |

### 四、HUD 布局

**战斗 HUD 位置分配**

```
┌──────────────────────────────────────────┐
│                                          │
│                                          │
│                    ● 连击计数器           │
│                    (mid-right)           │
│                                          │
│              [玩家角色]                   │
│            ○ 石青节奏环 ○                │
│          (角色脚下, world-space)          │
│                                          │
│  ■ 血条                ■■■■ 技能槽       │
│  (bottom-left)         (bottom-right)    │
└──────────────────────────────────────────┘
```

| 元素 | 位置 | 尺寸参考 | 备注 |
| --- | --- | --- | --- |
| 血条 | 屏幕左下 | 宽 180px，高 12px | **待原型验证**——备选方案：角色头顶（世界空间）。原型阶段测试两种方案的战斗可读性后定稿 |
| 连击计数器 | 屏幕中偏右 | 数字 28px，标签 13px | 静态显示，不随 BPM 呼吸 |
| 节奏环 | 角色脚下（世界空间） | 半径 = 角色横宽 110% | 锚定第3章石青节奏环规则 |
| 技能槽 | 屏幕右下 | 4格，每格 48×48px | 边框脉冲随 BPM 同步 |

**节拍指示器位置**：**待原型验证**——备选方案 A：节奏环内嵌缺口指示（当前默认）；备选方案 B：屏幕底部独立节拍条。原型阶段测试两种方案的节奏可读性后定稿。

### 五、信息密度控制

**「同时只允许一个视觉呐喊者」规则**

任何时刻，屏幕上最多只有一个元素处于「全强度视觉呐喊」状态。优先级（高→低）：

1. **结算面板**（出现时一切战斗 HUD 隐藏）
2. **连击阈值突破**（连击数到达 10 / 25 / 50 / 100 时，数字放大 + 金色闪光 1 秒）
3. **技能激活**（技能图标放大 120% + 绛红/石青边框高亮 0.5 秒）
4. **判定反馈**（Perfect 金光 / Miss 绛红边缘——已由第4章定义）

当高优先级呐喊者激活时，低优先级呐喊者自动压缩至静默态（无放大、无额外色彩、仅保留数值显示）。

**数字显示规则**

- HUD 数字（血量、连击数、伤害飘字）使用思源宋体 Bold，**不随 BPM 呼吸缩放**——数字的可读性高于节奏沉浸感
- 连击计数器字体缩放曲线：**待原型验证**——基础 28px，阈值突破时临时放大至 36-42px（具体缩放曲线在原型阶段通过手感测试确定）
- 伤害飘字：从命中点向上 + 略向右飘出，持续 0.8 秒淡出，字号 22px

### 六、技能卡片形态

**基本形态**

技能卡片基础比例为横向 4:1 竹简式（锚定第3章 UI 形态文法），四角 45° 斜切。

**竖向变体（允许）**：在技能详情面板或构筑（deck-building）界面中，允许使用竖向变体，比例 1:1.4（宽:高），保持 45° 斜切角。视觉参考：竹牍（单根竹片的窄长形态）。

**变体使用场景**

| 场景 | 卡片形态 | 理由 |
| --- | --- | --- |
| 战斗 HUD 技能槽 | 横向 4:1 或正方形 48×48px | 底部固定栏，横向排列 |
| 构筑 / 选牌界面 | 竖向 1:1.4 | 卡牌浏览需要更多垂直信息空间 |
| 奖励选择弹窗 | 竖向 1:1.4 | 与构筑界面视觉一致 |

**卡片颜色规则**：底色宣纸白 `#F5F0E8`，描边浓墨 `#1A1A18`，技能图标居中，技能名使用思源宋体 Regular 13px。稀有度通过描边粗细区分（普通 2px / 精英 3px / 传说 4px + 金色描边），不使用底色变化。

### 七、动画节奏与过渡

**UI 动画 BPM 同步表**

| 元素 | BPM 同步 | 动画类型 |
| --- | --- | --- |
| 节奏环缩放 | 是 | 呼吸式正弦波 |
| 技能槽边框 | 是 | 亮度脉冲（50% → 90% → 50%） |
| 血条变化 | 否 | 线性插值 0.3s |
| 连击数字更新 | 否 | 弹出式（scale 1.2 → 1.0，0.15s） |
| 面板展开/收起 | 否 | 竹简卷展动画 0.4s，ease-out |
| 判定文字（Perfect/Good/Miss） | 仅触发帧 | 出现 → 上飘 → 淡出，0.6s |

**竹简卷展动画**：所有面板（技能详情、地图、商店）的打开/关闭使用从右向左的卷轴展开动画（如同展开竹简），时长 0.4s，ease-out 缓动。关闭时反向卷合。此动画不受 BPM 影响——信息面板的打开速度是功能性需求，不是节奏需求。

## 8. 资源规范

*本章分为美术方向侧（格式、命名、分辨率、LOD、导出理念）与技术约束侧（面数、内存、材质、Importer、性能检查）。两侧数值冲突时以冲突折中方案（第十节）为准。*

### 一、文件格式偏好

#### 交付格式（美术团队提交）vs 引擎内格式（Unity 导入后）

格式选择是信息保全策略：交付格式必须保住美术决策的全部原始信息，引擎内格式负责运行时效率。

**2D 纹理（环境材质、道具表面）**

| 层级 | 交付格式 | 引擎内格式 | 理由 |
|---|---|---|---|
| 源文件 | `.psd`（保留图层） | — | 墨气浓度分层（底色层/笔触层/轮廓线层）必须可独立调整；合层不可逆 |
| 交付件 | `.png`（无损，32位） | `.png` → 引擎压缩 | 风格化纹理的笔触边缘对有损压缩敏感，轮廓线硬边不可引入 JPEG artifact |

**角色 Sprite / 模型贴图**

| 用途 | 交付格式 | 引擎内格式 | 理由 |
|---|---|---|---|
| 战斗模型贴图 | `.png`（32位，含 Alpha） | `.png` → 引擎压缩 | Alpha 通道承载轮廓抠图；皮影戏剪影美学中轮廓边缘精度是核心资产 |
| 立绘（对话/菜单） | `.psd`（图层保留：线稿/配色/底色）| 合层 `.png` 导入 | 立绘修改频率高；图层结构保留让配色变化可在源文件内完成 |
| 动作帧序列 | `.png` 序列（每帧独立） | Sprite Sheet（打包后导入）| 序列格式保持帧级独立修改能力 |

**环境资源**

| 类型 | 交付格式 | 说明 |
|---|---|---|
| 3D 模型 | `.fbx` | 风格化低多边形，无 PBR 烘焙；仅需顶点 + UV |
| 3D 模型贴图 | `.png`（无损）| 手绘风格化纹理 |
| 概念草图/参考板 | `.jpg` 可接受 | 仅团队参考，不进入构建管线 |

**UI 资源**

| 用途 | 交付格式 | 说明 |
|---|---|---|
| 所有 UI 元素 | `.png`（32位，含 Alpha）| 竹简面板底色与描边分两层交付，支持引擎内动态调整透明度 |
| 字体 | `.ttf` / `.otf` | 汉仪尚巍手书、思源宋体；商用授权文件一并归档 |
| 图标 | `.png`（32位）| 32×32px @ 1× + 64×64px @ 2× 双版本交付 |

**特效（VFX）**

| 用途 | 交付格式 | 说明 |
|---|---|---|
| 特效贴图 | `.png`（无损）| 笔触扫光需半透明 Alpha 渐变；禁止 `.jpg` |
| VFX 图集 | `.psd`（源）+ `.png`（交付）| 三色系统特效必须分层，支持颜色通道独立调整 |

### 三、纹理分辨率分级

分辨率决策标准：**在目标平台等距视角下，玩家实际能看到多少像素？**

**PC / Console（1080p 基准）**

| Tier | 适用资产 | 分辨率 | 理由 |
|---|---|---|---|
| T0 | 主角战斗模型、立绘 | 512×512 | 唯一高信息密度彩色单元；击败特写时须清晰 |
| T1 | 精英敌人、Boss 阶段贴图 | 256×256（Boss: 1024×1024） | 精英识别件约 30-60px；Boss 允许更高精度 |
| T2 | 普通敌人（量产） | 128×128 | 64×64px 灰度验收合格即可 |
| T3 | 大型环境件（廊柱、门扇） | 256×256 | 用于轮廓线精度，非纹理密度 |
| T4 | 中型道具（宫灯、武器架） | 128×128 | 深度锚点定位，低密度纹理 |
| T5 | 地面石板（Tileable） | 256×256 | 视觉面积最大单类资产 |
| T6 | UI 元素 | 控件最大显示尺寸 × 2 | 4K 显示器拉伸保护 |
| T7 | 特效贴图 | 64×64 或 128×128 | 运动中使用，低分辨率被运动模糊掩盖 |

**Mobile — 整体降一级**

| PC Tier | Mobile 对应 | 分辨率 |
|---|---|---|
| T0（512） | T0-M | 256×256 |
| T1（256） | T1-M | 128×128（Boss: 512×512） |
| T2（128） | T2-M | 64×64 |
| T3/T4 | T3-M/T4-M | 128×128 / 64×64 |

Mobile 降级后若无法通过 64×64px 灰度验收，上报 Art Director 评估剪影简化方案，不可直接降分辨率交付。

### 四、面数预算

等距视角可见面约为正交投影的 55-65%，面数预算可比自由视角同类游戏缩减约 30-40%。

| 资源类别 | PC / Console (tris) | Mobile (tris) | 说明 |
|---|---|---|---|
| 主角（含武器） | 800 | 500 | 轮廓关键区（耳、肩、袖）优先分配 |
| 主角武器（独立） | 200 | 120 | 不含主角身体计数 |
| 普通敌人 | 500 | 300 | 动画骨骼区域保留面数 |
| 精英敌人 | 700 | 400 | 更丰富的剪影特征 |
| Boss（单体） | 1,500 | 800 | Boss 战专用相机，允许更高预算 |
| NPC（非战斗） | 400 | 250 | 静态或极简动画 |
| 环境道具（小件） | 150 | 80 | 必须 GPU Instancing 兼容 |
| 建筑模块（拼接单元） | 600 | 350 | Tileable 模块优先降面 |
| 建筑装饰件（门楼、匾额） | 1,000 | 600 | 每场景同屏 ≤ 3 件 |

**帧顶点预算估算**（典型场景：主角×1 + 普通敌人×4 + 精英×1 + 道具×20 + 建筑×8）：
- PC/Console：约 **11,300 tris/frame**
- Mobile：约 **6,500 tris/frame**

帧预算瓶颈预计在 Draw Call 和 Overdraw，而非顶点处理。

### 五、纹理内存与压缩格式

**单场景纹理内存估算**

典型场景压缩后约 **4-8 MB**（含 Mipmap ×1.33），远低于 Mobile 512MB 上限。纹理内存非本项目瓶颈，但严禁超分辨率纹理占用预算。

**压缩格式推荐**

| 平台 | 格式 | bpp | 适用 |
|---|---|---|---|
| iOS | ASTC 6×6 | 2.67 | 所有纹理 |
| iOS（小纹理高质量） | ASTC 4×4 | 4.0 | 主角细节贴图 |
| Android | ASTC 6×6 | 2.67 | 默认；旧设备回退 ETC2 RGBA8 |
| PC / Console | DXT5 (BC3) | 4.0 | 含 Alpha；无 Alpha 用 BC1 |

单通道遮罩设置为 Single Channel，节省 75% 内存。禁止 Mobile 构建使用未压缩 RGBA32（LUT 除外）。

### 六、材质槽与 Shader 规范

**材质数量上限**

| 资源类别 | PC / Console | Mobile | 超限处理 |
|---|---|---|---|
| 主角（含武器） | 2 | 1 | 超限时合并至角色 Atlas |
| 普通敌人 | 1 | 1 | 强制单材质；变体用 MaterialPropertyBlock |
| 精英敌人 | 2 | 1 | 允许身体+甲胄分离 |
| Boss | 3 | 2 | 身体+甲胄+特效分离 |
| NPC / 环境道具 | 1 | 1 | 同材质道具打入同一 Atlas |
| 建筑模块 | 2 | 1 | Tileable + 可选细节叠加 |

**URP Shader 选择**

| 使用场景 | 推荐 Shader | 理由 |
|---|---|---|
| 角色主体 | 自定义 Unlit Shader Graph（带轮廓线 Pass） | 无需光照；SRP Batcher 兼容 |
| 环境道具/建筑 | URP/Unlit 或自定义 Unlit Shader Graph | Unlit 比 Lit 节省 20-30 条指令 |
| 特效材质 | 自定义 Unlit Shader Graph（Additive / Alpha Blend） | 透明排序在等距视角下可控 |
| Boss 甲胄高光 | URP Simple Lit | 仅 Boss 允许简单镜面高光 |
| UI | UI/Default 或 UI Toolkit USS | 不进入 3D 渲染路径 |

**禁止使用**：`Universal Render Pipeline/Lit`（全 PBR）用于角色或环境；多 SubShader 回退方案。

**Batching 规则**：SRP Batcher 为首选；重复道具启用 GPU Instancing；完全静止建筑可用 Static Batching（Mobile 优先 GPU Instancing）。同一资源禁止混用 Static Batching + GPU Instancing。

### 七、LOD 层级期望

等距固定相机下 LOD 的两个有效用途：**同屏单位数量驱动切换**（普通敌人 ≥9 个时远端切 LOD1）和**前/背景固定分配**（背景层天然对应低 LOD）。

**角色 LOD**

| 类型 | LOD 层数 | 说明 |
|---|---|---|
| 主角 | 2 | LOD0 完整 + 衣摆骨骼；LOD1 简化骨骼节点 50% |
| 普通敌人 | 2 | LOD1 在同屏 ≥9 时切换，多边形减 40%，保持轮廓 |
| 精英敌人 | 2 | LOD1 的非对称识别件必须保留 |
| Boss / NPC | 1 | 单体上场或数量极少，无切换需求 |

**环境 LOD**

| 类型 | LOD 层数 | 说明 |
|---|---|---|
| 大型建筑件 | 2 | LOD0 中景 / LOD1 背景固定分配 |
| 中小道具 / 地面 / 前景遮挡物 | 1 | 始终在中景层或数量受限 |

**LOD 过渡**：使用即时切换（无渐变），绑定游戏逻辑事件（如新波敌人刷新），避免静止画面中出现 LOD pop。

## 9. 参考方向库

*每个参考源明确标注「取什么」和「避什么」，防止「试图复制 X」的误读。参考是加法——没有两个参考指向完全相同的方向。*

### 参考一：Hades（Supergiant Games）

**取**：角色造型的「神话生物 + 人类可操控比例」平衡点。Hades 的角色在希腊神话原型上保留了非人特征（角、尾、翅），但身体比例完全服务于动作可读性。玉兔武侠的拟人化程度应对标此水准——兔耳和棉尾是身份标记，身体是武侠动作的容器。

**避**：Hades 的浓烈饱和色面板和大量描边内填色块。Hades 是西方神话的华丽感，本作是宋代院体画的克制感——颜色只在三色语义锚点上爆发，背景必须退入水墨灰度。

### 参考二：Crypt of the NecroDancer（Brace Yourself Games）

**取**：节奏驱动视觉的核心机制——地板格随 BPM 脉冲、全屏元素与音乐同步呼吸。NecroDancer 证明了「关掉音量仍能从画面感知节拍」的视觉设计目标是可实现的。本作的石青节奏环、屏幕边缘光晕、墨气闪动均从此理念延伸。

**避**：NecroDancer 的像素美术风格和色彩密度。像素风的信息密度在每格内均匀分布，本作的信息密度必须集中在角色和三色锚点上，背景大量留白。

### 参考三：Hi-Fi Rush（Tango Gameworks）

**取**：BPM 量化对战斗动画的具体实现——攻击前摇/后摇与节拍窗口的精准对齐，以及环境装饰物（路灯、霓虹灯）随 BPM 律动的「世界在呼吸」感。本作的原则二（脉搏先于装饰）直接继承此设计哲学。

**避**：Hi-Fi Rush 的卡通渲染（Cel Shading）和赛博摇滚美学。卡通渲染的均匀轮廓线与本作的水墨粗细变化线描冲突；赛博霓虹色系直接违反禁止方向一（赛博朋克/电子霓虹语言）。

### 参考四：宋代院体画（李唐、马远、夏圭）

**取**：构图中的「留白即叙事」——马远的「马一角」、夏圭的「夏半边」，画面大量空白不是未完成，是最有意图的表达。本作的墨气浓度系统（25-80%+）直接移植此美学：留白多 = 安全/沉淀，浓墨多 = 压迫/高潮。同时取界画传统的建筑描绘——硬直线、精准比例、秩序感。

**避**：院体画的静态性。宋画是凝固的时间切片，但游戏需要动态节奏。不可追求「像一幅画」而牺牲动态可读性——画面必须在 BPM 160 的战斗中仍然清晰可读。

### 参考五：中国皮影戏（陕西华县皮影）

**取**：剪影作为角色造型第一语言——皮影戏的角色在任何光源条件下都靠轮廓传达身份和情绪。本作的 64×64px 灰度验收标准直接来自皮影戏的设计约束：「如果去掉颜色和细节，你还能认出这是谁吗？」同时取皮影戏的动作夸张度——关节弧线大于真实解剖，传达武侠动作的「写意」而非「写实」。

**避**：皮影戏的平面性。传统皮影是 2D 投影，本作是 2:1 等距 3D——角色需要在三维空间中保持剪影可读性，这意味着模型的关键识别特征（长耳、武器角度）必须在等距俯视角下仍然突出，而非仅在正面侧视时可辨。
