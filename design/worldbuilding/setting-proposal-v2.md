## 0. 提案摘要

你扮演的玉兔，原是这座天朝最底层的劳工：日复一日在药坊跪地捣制长生药，好让高居补子之上的「衣冠禽兽」们永世不朽。有一天它放下药杵，操起兵器，开始破阵。

它要打碎的，是一座**字面意义上**由「禽」（文官）与「兽」（武官）组成的朝廷，一台靠「万骨枯」的战争与底层的劳作供养权贵永生的机器。而最深的讽刺在于：要破这台以《破阵乐》自我歌颂的战争机器，玉兔必须自己也踩着同一支军乐，成为一件兵器。在「兔死狗烹」的循环里，它本是那只功成之后该被烹的兔，而它偏不。

这套设定把游戏已有的三个词（**玉兔**、**破阵**、**拟人鸟兽朝廷**）从「好看的皮肤」升级成「有史实根、有寓意、有批判」的世界观内核，且不推翻任何已定的玩法与美术规则。

## 1. 四大文化支点（研究结论）

### 支点一：破阵乐 · 节奏与战斗本就是一体

《秦王破阵乐》是唐初军歌：公元 620 年秦王李世民破刘武周而作；贞观七年（633）李世民亲制《破阵舞图》，命吕才教乐工一百二十八人「披甲执戟而舞」，「舞有三变，每变四阵，共五十二遍」，箫管歌妓合奏合唱。其派生词牌《破阵子》又名**《十拍子》**，本是唐教坊为这支慷慨武舞而生的曲调，宋代定型为双调六十二字。

**设计含义**：「踩着拍子破阵」不是你发明的机制，而是这个词一千四百年前的**本义**。这款游戏，本质上是把《破阵乐》做成了可玩的东西。这直接坐实支柱一「节奏即战斗」的文化正当性，而不是把节奏当作外挂的装饰层。

### 支点二：衣冠禽兽 + 补子 · 现成、且是史实的讽刺骨架

明洪武二十四年（1391），朱元璋定「补子」制：**文官绣禽，武官绘兽**，以补子上的不同鸟兽区分官阶。「衣冠禽兽」一词本为中性甚至褒义，是「当官的」的代称；到明朝中晚期官场腐败（民间概括为「文官爱钱，武将怕死」，欺压百姓无恶不作），这个词才转为贬义，最早的贬义用例见明末陈汝元《金莲记》。

**设计含义**：一个拟人鸟兽组成的朝廷，字面上就是「衣冠禽兽」。而这个词**从褒到贬的堕落史**，本身就是一段「一座朝廷如何烂掉」的现成叙事。世界观的中心意象天然自带反讽，不需要额外解释。

### 支点三：玉兔捣药 · 主角是永生机器的底层劳工

玉兔捣药出自汉乐府《董逃行》：月中白兔跪地，以玉杵捣制不死药（蛤蟆丸），服之可长生成仙。玉兔象征长生、旺盛的生命力与祥瑞。

**设计含义**：主角的原初身份，是这套官僚永生机器里**最底层的工人**。它「放下药杵、拿起兵器」的转身，天然是一次阶级反抗；而它**没有补子、不在等级序列内**，所以恰恰是它，才有资格去打破这套等级。药杵与兵器（苗刀）在造型与叙事上可以互文：一柄「开了刃的捣药杵」。

### 支点四：兔死狗烹 / 一将功成万骨枯 · 阶级批判与反战共用一根脊柱

「狡兔死，走狗烹；飞鸟尽，良弓藏；敌国破，谋臣亡」，语出范蠡（越王勾践灭吴后）与韩信临刑之叹。它字面同时含**兔**（主角）、**狗**（守卫敌人）、**鸟**（文官）、**弓**（武备）：整个卡司都在这一句成语里。喻义：大功告成之后，权力就抛弃、乃至烹杀出过力的人。

曹松《己亥岁》（约 880 年，晚唐）：「泽国江山入战图，生民何计乐樵苏。凭君莫话封侯事，**一将功成万骨枯**。」这是中国反战诗的定谳之句，直陈阶级矛盾：权贵的功名，建在千万士卒的白骨上。

**设计含义**：这两条把「暗黑阶级批判」与「反战」焊成同一个主题。破阵（敌国破）→ 谋臣亡：**赢得战争本身，就摧毁了赢家的价值**。玉兔正是那只「功成后该被烹的兔」，而它拒绝这个结局。辛弃疾《破阵子·为陈同甫赋壮词》（醉里挑灯看剑……可怜白发生）则以「壮志未酬、以壮衬悲」定下全篇的情绪底色。

## 2. 时代与世界：架空复合天朝

### 2.1 为什么架空

三个支点分属三个朝代：破阵乐（唐）、补子 / 衣冠禽兽（明）、现有 art-bible 的院体画美术与辛弃疾（宋）。锚定任何一个真实朝代，都会与其余两个打架。**架空复合天朝**把它们统一为一个神话化的天界官僚朝廷：这不是历史考据，是寓言。它也贴合玉兔 / 月宫的神话框架（参照《西游记》：天庭本就是人间官僚制度的神话映射）。

| 元素 | 取自 | 在架空天朝里的角色 |
|---|---|---|
| 视觉语言：宋代院体画、界画、皮影剪影 | 宋 | 画卷的「肉身」，视觉底色**完全保留**现有 art-bible |
| 官阶制度：补子「文禽武兽」 | 明 | 世界观的社会结构 + 敌人分层的骨架 |
| 核心乐 / 战：破阵乐、十拍子 | 唐 | 战斗节奏系统的文化正当性 |
| 情绪底色：辛弃疾《破阵子》 | 南宋 | 壮志未酬、以壮衬悲的苍凉 |
| 主题脊柱：一将功成万骨枯、兔死狗烹 | 晚唐 / 先秦 | 反战 + 阶级批判 |

**一句话口径**：这不是宋、不是明、不是唐，是一座「本该存在于每一个王朝、又不属于任何王朝」的天朝。美术是宋的骨，制度是明的皮，乐是唐的血，魂是辛弃疾的苍凉。

### 2.2 天朝的结构：一座随乐呼吸的「阵」

把整座朝廷想成一个巨大的、随《破阵乐》呼吸的军阵（阵）。玉兔从最底层的药坊出发，向上一层层「破阵」，每一层对应更高的补子官阶，越往上，禽兽越华美、腐败越深。顶端，是这台永生机器的核心。

地点分层建议（对齐 art-bible 第 4 章「区域 / 场景色温规则」的外廷 / 内廷 / 禁苑 / 禁地）：

| 区域 | 对应 art-bible 区域 | 居住者 | 主题功能 |
|---|---|---|---|
| **药坊**（起点 / 底层） | 新增（可并入禁苑的边缘） | 捣药的兔与劳役牲口 | 玉兔的出身，劳工空间，教程房 |
| **外廷 · 武营** | 外廷（权贵走廊） | 武官兽（海马→狮） | 武力递进，主战斗层 |
| **内廷 · 禽阁** | 内廷（秘室 / 典籍库） | 文官禽（鹌鹑→仙鹤） | 秩序、科场、朝会 |
| **御史台 · 法场** | 禁地边界 | 獬豸 | 法治已死的反讽之战 |
| **顶阙 · 长生炉** | 禁地（腐化区域） | 永生机器核心 / 终局 Boss | 终章，一切劳作与白骨的去向 |

> 说明：art-bible 已把「禁地」定义为「不属于正常宫廷体系、突破三色的紫色异界」。把「长生炉 / 永生机器核心」放在禁地，语义完全自洽：**永生本身就是反常、异界、不可解释之物**。

## 3. 讽刺与反思：三层主题

三层由浅入深，共用辛弃疾式的苍凉基调，可按玩家推进逐层揭示（氛围叙事，非主线剧情，锚定 game-concept「NOT 剧情主导」）。

### 层一 · 阶级：长生药机器

谁劳作（兔与劳役牲口）、谁送死（万骨 / 士卒）、谁永生（补子权贵）。玉兔捣的药，就是权贵的不死之身。反抗的第一步不是杀戮，是**停止供药**，然后破阵。

> **设计验证题**：讨论「给玉兔安排一个失散的高贵王族血统」。这层主题说：**不**。玉兔的力量来自「它是劳工」，不是「它其实是隐藏的贵族」。血统叙事会立刻消解阶级批判，把「底层反抗」偷换成「贵族复位」。

### 层二 · 反战：破阵乐的反讽

《破阵乐》本是帝王武功的颂歌。反讽在于：朝廷用《破阵乐》歌颂自己的赫赫战功，而战功的真相正是「一将功成万骨枯」。玉兔的破阵，是一支**反破阵乐**：用同一支军乐反打回去。代价（辛弃疾式的苍凉）在于：要破这台战争机器，它不得不**成为兵器**，踩着军乐去杀戮。赢，就是变成你所对抗之物。

> **设计验证题**：讨论「加一条纯净无瑕、零杀戮的通关路线作为默认爽路线」。这层主题说：**慎重**。反战的重量恰恰来自「不得不战」的自我背叛；一个无代价的和平结局会架空反思。可作为**隐藏结局**讨论，但不设为默认路线。

### 层三 · 循环：兔死狗烹

「狗」（守卫敌人）也是被朝廷用完就烹的工具，与玉兔同源。可设计特定事件让某个狗敌人显露「与玉兔同为弃子」的处境（叙事同情，不削弱战斗）。终局留白：打碎这台机器后，玉兔会不会成为新的顶点，开始新一轮的兔死狗烹？

> 情绪底色统一由辛弃疾《破阵子》定调：**醉里挑灯看剑，梦回吹角连营……可怜白发生。** 以壮衬悲，是全篇的温度。

## 4. 角色动物选定体系（核心交付）

配套结构化数据见 `design/worldbuilding/animal-roster.json`（字段可对齐 entities.yaml 与未来 EnemyInfoSO）。

### 4.1 主角：玉兔

- **为什么是兔**：① 玉兔捣药的神话给了「底层劳工」出身；② 兔死狗烹的「狡兔」给了核心处境；③ 兔无补子、不在衣冠禽兽等级内，是唯一有资格破阵的局外人；④ 长耳剪影已在 art-bible 锁定为最高辨识点。
- **武器互文**：捣药玉杵 ↔ 兵器。现有 MVP 武器苗刀，可解读为「一柄开了刃的药杵」；长枪 / 剑为后续。
- **反英雄基调**：不是天选之子，是被逼到放下药杵的劳工。锚定层一主题。
- **与现有 art-bible 一致**：朱砂袍、月白内衬、长耳、皮影剪影全部保留，本提案只是给了「他是谁、为何而战」的寓意根。

### 4.2 敌人分层 = 补子等级制（关键设计动作）

**把敌人的难度层级，直接映射到补子官阶的高低。** 越高阶，禽兽越华美、越难打、腐败寓意越深。分两条轴 + 一个特殊：

**A. 武官兽（近战战斗主力，难度由低到高 = 官阶由低到高）**

|---|---|---|---|---|
| 九品 | **海马** | 武官之末，海中小兽 | 最底层的爪牙、可悲的炮灰，与玉兔同为被驱使者 | 教程 / 最弱杂兵（**MVP 普通敌人首选**）|
| 八品 | **犀牛** | 皮甲厚重，心有灵犀 | 有勇无谋的重甲兵，只认命令 | 重甲盾兵，破防设计（呼应苗刀 X-X-X 第三击破防）|
| 六 / 七品 | **彪** | 小虎、虎之幼，寓勇力 | 仗着「虎」的余威狐假虎威的中低层军头 | 成群中阶兵 |

### 4.3 Boss 阵容建议

1. **御史台 · 獬豸（法治已死）**：中后期 Boss，反讽核心。玩家会本能地期待「执法神兽是友军」，而它偏是敌人，冲击力强。
2. **顶阙 · 仙鹤（一品，永生机器门面）**：终局 Boss 强候选。「圣洁长寿」的最高文官，正是整台机器最想维持的假面。
3. **武营 · 狮（外来门面武力）**：可选平行 / 前置 Boss。
4. **关于 PRD F3 的「乌鸦 Boss」**：乌鸦不在补子体系内。建议二选一：（a）**重定位**为体系外的存在（不祥之兆 / 盗火者 / 被朝廷抹去官籍的前御史，反而强化体系批判）；（b）用獬豸或孔雀替换首发 Boss。此项需与 PRD 对齐，列为 open question。

### 4.4 NPC（对齐现有 art-bible）+ 一条讽刺机制化的规则

现有 art-bible 第 5 章已定 NPC：商人（兔 / 羊）、铁匠（熊 / 牛）、典籍官（鹤 / 白鹭）。与本体系的冲突与调整：

- **典籍官 = 鹤**：鹤现被定为一品文官（最高官 / 终局 Boss 门面）。建议典籍官改用**鹭**（六品鹭鸶的退休 / 边缘版）或**鹌鹑**（九品明哲保身的老吏），把「鹤」专留给权力顶点。
- **商人 = 兔**：与主角同为兔，可强化「兔 = 底层 / 平民」的阶级线。商人兔是「没有造反的那部分兔」，玉兔是「造反的那一只」。叙事红利，建议保留。
- **铁匠 = 熊**：熊是五品武官兽。为让 NPC 与敌人不撞，铁匠建议改**牛**（无补子的劳役牲口，呼应劳工主题），把熊专留给敌人。

> **一条把讽刺主题机制化的规则**：
> **有补子 = 体制内 = 敌；无补子 / 劳役牲口 = 体制外 = 友 / 主角。**
> 玩家不需要读任何文字，就能从「这只动物身上有没有补子」瞬间读出敌我与阶级。这条规则同时服务于 art-bible 的「敌我一眼可读、战场噪音极低」原则，把世界观直接变成可玩的视觉语言。
