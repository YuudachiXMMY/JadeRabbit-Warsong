# 苗刀节奏手感切片 — 试玩测试清单 / M0 Evidence

> **用途**: `/vertical-slice` 手感首轮试玩的可勾选测试记录，作为 **M0 节奏手感验收** evidence 归档。
> **验证风险**: R-FEEL-01（节奏手感未验证 — #1 Critical）
> **判据来源**: `production/milestones/m0-rhythm-feel-acceptance.md`（A 手感即奖励 / B 反支柱护栏 / C 无线音频 / D 技术真值）
> **被测对象**: `Assets/_VerticalSlice/MiaodaoRhythmSlice/`（切片代码，非生产）
> **创建**: 2026-08-17

## 如何使用

1. **先自然玩 1 遍只感受手感**——别边玩边勾，会破坏心流。
2. 再带清单玩 2–3 遍逐项验；每条右侧 `[A]/[B]/[C]/[D]` 标注它喂哪组 M0 判据。
3. ⚠️ 标记 = **红线级**发现，命中任一务必在「具体场景记录」里写清。
4. 每位测试者/每场复制一份「会话元数据」块填写。M0 正式协议要求 **≥3 场、≥5 名测试者（含 ≥2 名非节奏玩家）**；本文件按场累积。
5. 填完把「反馈汇总」交回，汇成 `REPORT.md` 出 PROCEED/PIVOT/KILL 裁决。
